# Шаблоны политик информационной безопасности (Русский)

Репозиторий содержит готовые к использованию **шаблоны политик информационной безопасности** для организации.  
Документы написаны в профессиональном стиле и содержат плейсхолдеры, которые необходимо заменить на данные конкретной компании.

## Включённые политики

1. **Политика информационной безопасности** (высокоуровневая)
2. **Политика управления доступом**
3. **Политика паролей**
4. **Политика допустимого использования**
5. **Политика классификации и обработки данных**
6. **Политика реагирования на инциденты**
7. **Политика удалённой работы / BYOD**

## Как использовать

1. Замените все плейсхолдеры в квадратных скобках: `[Название компании]`, `[Дата]`, `[Владелец]` и т.д.
2. Адаптируйте содержание под юрисдикцию, отрасль и риск-аппетит.
3. Согласуйте с Legal, HR и службой информационной безопасности.
4. Получите формальное утверждение у высшего руководства.
5. Доведите политики до всех сотрудников и зафиксируйте ознакомление.
